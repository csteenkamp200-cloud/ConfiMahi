 3. PROJECT TREE — SERVER / BUILD HUB (C:\Users\PC\Downloads\IsleExtServer\)
================================================================================

IsleExtServer\
|
|-- deploy.bat                  * DOUBLE-CLICK THIS TO SHIP UPDATES
|                                  Calls deploy.ps1.
|
|-- deploy.ps1                  Builds both EXEs then runs upload.ps1:
|                                  1. Compiles main.cpp   -> %APPDATA%\Mahi\IsleExt.exe
|                                  2. Compiles loader.cpp -> IsleExt\bin\Loader.exe
|                                  3. Calls upload.ps1
|
|-- upload.ps1                  Pushes 10 files to Railway via raw PUT:
|                                  Loader.exe  -> server public\
|                                  index.html  -> server public\
|                                  other 8     -> server private\
|
|-- server.js                   Express server running on Railway.
|                                  Routes:
|                                    GET  /                    -> landing page
|                                    GET  /Loader.exe          -> public download
|                                    GET  /dl/<file>           -> token-gated (X-Token header)
|                                    PUT  /upload/<key>/<file> -> admin only
|                                    GET  /list                -> JSON listing
|
|-- package.json                Node dependencies (express, multer).
|-- package-lock.json           Locked dependency versions.
|
|-- public\                     Uploaded by upload.ps1 (server-side only):
|   |-- index.html              Landing page — title "Mahi Loader".
|   \-- Loader.exe              Uploaded.
|
|-- private\                    Uploaded by upload.ps1 (server-side only):
|   |-- IsleExt.exe             external cheat
|   |-- IsleDma.exe             DMA cheat
|   |-- gabyzuum.sys            kernel driver
|   |-- kdmapper.exe            driver loader
|   |-- vmm.dll                 DMA library
|   |-- leechcore.dll           DMA library
|   |-- FTD3XX.dll              FTDI USB driver
|   \-- map.png                 The Isle map
|
|-- secrets.txt                 * KEEP PRIVATE. Contains:
|                                  SHARED_TOKEN (auth for /dl/)
|                                  ADMIN_KEY    (auth for /upload/)
|                                  Also backed up to Documents\.
|
\-- README.txt                  Quick deploy instructions.

Who writes here:
  - Loader.exe writes the 8 runtime files on first launch.
  - IsleExt.exe / IsleDma.exe write configs, key.dat, autoload.txt.
  - Users delete this folder to start fresh.

 6. EXTERNAL SERVICES
================================================================================

1) Railway  --  https://mahi-production-059f.up.railway.app
   - Hosts server.js
   - Runs 24/7 on their free tier
   - Has two env vars: SHARED_TOKEN, ADMIN_KEY
   - Contains the 10 files after upload.ps1 runs
   - Landing page title: "Mahi Loader"

2) KeyAuth  --  keyauth.win
   - Your cheat's license backend.
   - secrets.hpp contains encoded KA_NAME, KA_OWNER, KA_HOST.
   - IsleExt.exe and IsleDma.exe both verify on launch.
   - Heartbeat loop re-checks every 5 minutes.

================================================================================

  User double-clicks Loader.exe
        |
        v
  Loader reads embedded SHARED_TOKEN + UpdateUrl()
        |
        v
  Loader window title: "Mahi"
        |
        v
  Checks %APPDATA%\Mahi\ for each of 8 files
        |
        v
  Missing -> HTTP GET https://.../dl/<file> with X-Token header
        |
        v
  Server: header matches SHARED_TOKEN -> serve file
        |
        v
  Loader writes file to %APPDATA%\Mahi\
        |
        v
  All 8 present -> show tabs
        |
        v
  User clicks "Load Driver" -> kdmapper.exe gabyzuum.sys (UAC)
        |
        v
  User clicks "Launch Cheat" -> CreateProcess IsleExt.exe
        |
        v
  IsleExt authenticates to KeyAuth -> runs

 12. QUICK REFERENCE — HOW TO DO THINGS
================================================================================

  Ship an update:
    Double-click  IsleExtServer\deploy.bat

  Run the external for debugging:
    & "$env:APPDATA\Mahi\IsleExt.exe" debug

  Run the DMA for debugging:
    & "$env:APPDATA\Mahi\IsleDma.exe"

  Run the loader:
    & "C:\Users\PC\Downloads\IsleExt\bin\Loader.exe"

  Rebuild only the DMA:
    cmd /c 'C:\Users\PC\Downloads\TheIsleDma\Ice\src\_build.bat'

  Wipe runtime + test fresh install:
    Rename  %APPDATA%\Mahi  to  Mahi.bak
    Run  IsleExt\bin\Loader.exe  and watch it download all 8.

  Rotate the shared token:
    Edit  IsleExtServer\secrets.txt  -> new SHARED_TOKEN
    railway variables set SHARED_TOKEN=<new>
    Rebuild + upload (deploy.bat)   -> new loader has new token inside

  Rotate the admin key:
    Edit  IsleExtServer\secrets.txt  -> new ADMIN_KEY
    railway variables set ADMIN_KEY=<new>
    Update upload.ps1 to use the new key
